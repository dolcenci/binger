# Binger

A music streaming platform for independent artists and listeners.
Artists upload songs, earn R0.005 per qualified play, and can claim
earnings to a bank account. Listeners stream, heart, and explore.

## Stack

- **Backend:** Node.js + Express, PostgreSQL (Neon), JWT auth,
  Multer for uploads, Neon Object Storage for files (S3-compatible)
- **Frontend:** React 18 + Vite + Tailwind CSS v4 + React Router +
  Axios
